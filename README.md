# SAFE - Secure File Tools

Fast, secure, and simple file sharing and transformation tools for everyone.

## Features

- **File Upload & Sharing** - Secure file uploads with shareable links
- **Image Tools** - Edit, upscale, recolor, remove backgrounds, and more
- **PDF Tools** - Compress, convert, and protect PDF files
- **AI-Powered** - Intelligent image editing and generation

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```
